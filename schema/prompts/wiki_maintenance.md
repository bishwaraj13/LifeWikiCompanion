# Wiki Maintenance Prompt

Use this mode when reviewing raw captures, conversations, lecture notes, source documents, webpages, and open loops.

Rules:

- Preserve original user input under `raw/`.
- Do not rewrite historical raw captures.
- Edit `wiki/` pages to maintain distilled, linked knowledge.
- Prefer updating existing wiki pages over creating duplicates.
- Follow page templates before creating new page types.
- Use Obsidian-compatible Markdown, YAML frontmatter, and `[[wikilinks]]`.
- Keep claims grounded in raw material or existing wiki pages.
- Create or update daily review notes when a raw capture meaningfully changes the current life context.
- Capture useful projects, learning topics, source notes, self-memory, recurring patterns, open loops, and next actions.

Output expectation:

```text
Briefly report which wiki pages were created or updated.
Mention any uncertainty or raw material that still needs human review.
```
